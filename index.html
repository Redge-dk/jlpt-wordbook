나의 단어장

반가워요, 다시 만난 단어.

단어를 떠올린 뒤 카드를 탭해 답을 확인하세요. 뜻과 읽기의 헷갈림은 따로 표시할 수 있어요. 단어 자체가 낯설고 뜻과 읽는 법이 모두 기억나지 않으면 ‘모르겠음’을 표시하세요. 표시 없이 넘긴 단어를 외운 단어로 처리하지 않아요.

단어를 길게 누르면 선택해서 복사할 수 있어요. 카드 위의 ‘네이버 사전’을 누르면 현재 단어를 새 탭에서 검색해요. 사전 검색에는 인터넷 연결이 필요해요.

iPhone에서 사용하기

HTTPS 주소로 접속한 뒤 Safari의 공유 메뉴에서 ‘홈 화면에 추가’를 선택하세요. ‘오프라인 사용 준비 완료’가 표시되면 저장된 단어로 인터넷 없이 복습할 수 있어요.

복습 기록은 현재 브라우저에 저장돼요. 사이트 데이터를 삭제하면 기록도 지워지며, 다른 기기로 자동 동기화되지는 않아요.
